№ 9

Выяснение условий плавания тела в жидкости

Сравните силу тяжести, действующую на пробирку с песком, с выталкивающей силой воды и установите, когда пробирка тонет, плавает или всплывает.

Цель работы
Выяснить условия плавания тела в жидкости, сравнив силу тяжести и выталкивающую силу.
Приборы и материалы
Пробирка (аптечный пузырёк) с пробкой и нитью, сухой песок, вода, измерительный цилиндр, электронные весы, салфетка.

Указания к работе

  1. Налейте воду в измерительный цилиндр и запишите её объём V₁. Взвесьте пробирку с песком; для каждого опыта меняйте количество песка.
  2. Опустите пробирку в воду, не касаясь стенок и дна цилиндра. Запишите новый объём воды V₂ и отметьте, тонет пробирка, плавает или всплывает.
  3. Повторите наблюдение для нескольких масс пробирки с песком. Для каждого опыта определите объём вытесненной воды: V = V₂ − V₁.
  4. Обработка результатов измерений. Рассчитайте силу тяжести Fтяж = mg и выталкивающую силу FА = ρводыVg. Для воды примите ρ = 1000 кг/м³, g = 10 Н/кг.
  5. Сравните силы в каждом опыте. Если FА меньше Fтяж, тело тонет; при равенстве сил оно находится в равновесии; если выталкивающая сила больше, тело всплывает.
  6. Проанализируйте измерения и сделайте вывод об условии плавания тела в жидкости.
Заполнение таблицы. Введите массу пробирки с песком в граммах и показания цилиндра в миллилитрах (1 мл = 1 см³). Сила тяжести и выталкивающая сила рассчитываются автоматически. Поведение пробирки определите по сравнению сил и запишите наблюдение.

Формулы для расчёта

Fтяж = mgFА = ρводыVgСравните FА и FтяжМасса переводится из граммов в килограммы, объём — из см³ в м³; для воды FА = 0,01V Н, если V задан в см³.

Контрольный расчёт из видео. Для первого опыта: V = 180 − 160 = 20 см³, FА = 0,20 Н, Fтяж = 0,205 Н. Для третьего: V = 188 − 160 = 28 см³, FА = 0,28 Н, Fтяж = 0,276 Н.
Вывод

Сравните выталкивающую силу с силой тяжести для каждого опыта и сформулируйте условие плавания тела в жидкости.

Для вывода используйте результаты наблюдений и условие FА = Fтяж для равновесного плавания.
